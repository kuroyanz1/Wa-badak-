04 / FAQ
Kenapa tombol Grup Laporan tidak langsung ke WhatsApp?

Karena laporan ditangani di website: pelapor membuat tiket dan admin membalas dari panel admin. Grup WhatsApp hanya komunitas eksternal.

Apakah mode Public/Self langsung mengubah bot?

Belum. Build ini menyimpan state di browser. Untuk perubahan bot nyata diperlukan endpoint API terautentikasi milik WA Badak.

Apakah menu dashboard sudah lengkap?

Struktur navigasi mengikuti menu dashboard ZEKAIS yang terlihat di web saat ini: dashboard, statistik, chat admin, shop, langganan, lapor/bantuan, profil, tambah bot, serta menu situs.
